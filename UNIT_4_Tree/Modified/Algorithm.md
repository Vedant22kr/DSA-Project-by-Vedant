1.	Start the program and define the input sizes 5, 10, 20, 50, and 100.
2.	For each input size n, generate values from 1 to n.
3.	Create ascending, descending, and shuffled random insertion sequences.
4.	Build a separate BST for each sequence.
5.	Calculate the height of the tree recursively.
6.	Search for every stored key and total the comparisons; calculate the average successful comparisons.
7.	Search for keys 0 and n+1; calculate the average unsuccessful comparisons.
8.	Display input size, insertion order, height, average successful comparisons, and average unsuccessful comparisons in a table.
9.	Free the tree nodes and continue with the next insertion order and input size.
10.	Stop the program.
