Problem Statement For Singly Linked List

Managing railway coaches becomes difficult when coaches need to be added, removed, searched, or displayed dynamically. A fixed-size array is not ideal because the number of coaches may change during operation. The Train Coach Management System provides a simple way to manage coaches using a Singly, Doubly and Circular Linked List. Each coach is stored as a node containing the coach number, coach type, and a pointer to the next coach.
The system supports adding a coach, removing a coach, searching for a coach, displaying all coaches, and exiting the program. Dynamic memory allocation is used so that memory is created when a coach is added and released when a coach is deleted.
