Objectives of Singly Linked List

•	To implement railway coach management using a Singly Linked List.

•	To dynamically add new railway coaches without using a fixed-size array.

•	To remove a coach using its coach number.

•	To search for a particular coach by traversing the linked list.

•	To display all available coaches and their details in sequence.

•	To understand dynamic memory allocation using new and delete.

•	To demonstrate practical applications of insertion, deletion, searching, and traversal.
