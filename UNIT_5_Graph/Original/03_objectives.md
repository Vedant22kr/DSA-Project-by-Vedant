•	Objectives

1.	To represent the smart-city road network as a weighted graph using an adjacency list.
2.	To implement Dijkstra’s algorithm for non-negative road distances.
3.	To calculate the shortest distance from a source junction to every reachable junction.
4.	To display reachable junctions in ascending order of their shortest distances.
5.	To reconstruct and display the shortest path to a selected destination junction.
6.	To validate user inputs and report when a destination cannot be reached.
