Objectives of Doubly Linked List 

•	To understand the structure and operation of a Doubly Linked List.
•	To create coach nodes dynamically using pointers.
•	To insert and delete coach records while maintaining both prev and next links.
•	To search for a coach using its coach number.
•	To traverse and display the train in forward and reverse directions.
•	To count the coaches and release dynamically allocated memory safely.
